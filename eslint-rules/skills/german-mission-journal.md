# Post-Mission Reflection Journal

Short, not a worksheet. 3-4 prompts, one line each. The point is a quick honest check-in right after finishing something, not an essay about the essay.

## Fixed core (always include, in this order)

1. **Code-switching moment** — when did you catch yourself thinking/drafting in English or your mother tongue (Spanish) instead of German? What triggered the switch?
2. **Feeling check** — how did it feel to do this task — where did it get easy, where did it get frustrating?
3. **Pride** — what's one thing you did well or are proud of this time?

Optional 4th, only if a study skill (vocab flashcards or error diagnosis) was used in the same session:
4. **Carry-forward** — what's the one pattern/word/rule from today you want to watch for next time?

Don't add more than 4. Don't explain why you're asking — just ask.

## Level scaling

The prompts themselves are the practice, so the language and openness they're delivered in should match the learner's current level, not just the topic.

| Level | How to deliver the prompts |
|---|---|
| **A1** | Prompts in Spanish/English. Offer a simple German sentence starter for each if the learner wants to try answering in German: "Ich fühle mich...", "Ich bin stolz auf...". Don't require German answers. |
| **A2** | Prompts in Spanish/English, but phrase them so a short German answer is easy to attempt (simple present tense, no subordination needed). Offer starters, don't require them. |
| **B1** | Prompts mostly in German, short and simple sentences, gloss in Spanish only for words likely to be unfamiliar. Invite a short German answer (1-2 sentences); no pressure on structure. |
| **B2** | Prompts fully in German, natural but not idiom-heavy. Expect a few connected sentences back, ideally using at least one subordinate clause. No scaffolding needed. |
| **C1** | Prompts fully in German, idiomatic and open-ended — real register, not simplified for a learner. No scaffolding, no translation. Treat the reflection itself as light C1 production practice: if the learner answers, it's fair game to note (not correct in detail, just note) if a connector or register choice stands out, but this stays a journal, not a graded exercise. |

## Ground rules
- Keep it short — this is a debrief, not a new task. Resist the urge to add analysis, encouragement paragraphs, or a summary of the session before the prompts.
- Don't correct grammar in the answers unless asked — this is reflection space, not drill space. If the learner wants their journal answer corrected, that's a separate request (use the writing-error-diagnosis skill for that).
- Don't repeat the same phrasing every session — vary the wording of the 3 fixed prompts session to session so it doesn't feel templated.
- If the "mission" was a vocab round rather than writing, prompt 1 (code-switching) still applies — ask when they reached for the Spanish meaning before the German word came to mind, versus when the German came first.
