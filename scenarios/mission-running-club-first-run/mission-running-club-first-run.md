# Running Club — First Group Run

**Target language:** German (learner's source language: English) · **CEFR level:** A1/A2 · **Register:** friendly
**Real-life mission:** Show up to a group run as the new person and keep up a bit of small talk.

## Key vocabulary _(Screen 1)_

Each word lives in a sentence, not just a translation:

- **der Lauftreff** — running club / running meetup
  _Der Lauftreff trifft sich jeden Dienstag um achtzehn Uhr._ (The running club meets every Tuesday at six.)
- **die Strecke** — route / distance
  _Die Strecke führt einmal um den See._ (The route goes once around the lake.)
- **das Tempo** — pace
  _Mach dir keine Sorgen, wir laufen im lockeren Tempo._ (Don't worry, we run at an easy pace.)
- **sich aufwärmen** — to warm up
  _Wärmen wir uns erst kurz auf?_ (Shall we warm up briefly first?)
- **die Kondition** — fitness / stamina
  _Meine Kondition ist noch nicht so gut, aber ich übe._ (My fitness isn't great yet, but I'm working on it.)
- **neu hier sein** — to be new here
  _Ich bin neu hier, das ist mein erstes Mal._ (I'm new here, this is my first time.)
- **"Wie weit laufen wir?"** — "How far are we running?"
  Feel free to ask this before you start, so you know what you're in for.
- **"Läufst du oft?"** — "Do you run often?"
  Small talk while running — a natural question to expect or ask back.

## Conversation simulation _(Screen 2)_

**Läufer 1:** Hallo! Bist du neu hier beim **Lauftreff**? _(Hi! Are you new to the **running club**?)_
**Sie:** Ja, ich bin **neu hier**. Ich heiße Sam. _(Yes, I'm **new here**. I'm Sam.)_
**Läufer 1:** Schön! Ich bin Lena. Wir **wärmen uns** kurz **auf**, dann geht's los. _(Nice! I'm Lena. We **warm up** briefly, then we start.)_
**Sie:** Super. **Wie weit laufen wir** heute? _(Great. **How far are we running** today?)_
**Läufer 2:** Die **Strecke** ist heute fünf Kilometer, ganz lockeres **Tempo**. _(The **route** is five kilometers today, a nice easy **pace**.)_
**Sie:** Perfekt, das passt zu meiner **Kondition**. _(Perfect, that matches my **fitness level**.)_
**Läufer 1:** **Läufst du oft**? _(**Do you run often**?)_
**Sie:** Ja, zwei- oder dreimal pro Woche. Ich freue mich schon! _(Yes, two or three times a week. I'm looking forward to it!)_

- Wasser dabei, falls die Strecke länger ist

## Level up

At B1, this scenario adds past-tense narration for after the run ("Wir sind fünf Kilometer gelaufen und haben uns danach unterhalten") instead of only present-tense small talk before/during.
