# Running Club — First Group Run

**Target language:** German (learner's source language: English) · **CEFR level:** A1/A2 · **Register:** friendly
**Real-life mission:** Show up to a group run as the new person and keep up a bit of small talk.

## Key vocabulary *(Screen 1)*

Each word lives in a sentence, not just a translation:

- **der Lauftreff** — running club / running meetup
  *Der Lauftreff trifft sich jeden Dienstag um achtzehn Uhr.* (The running club meets every Tuesday at six.)
- **die Strecke** — route / distance
  *Die Strecke führt einmal um den See.* (The route goes once around the lake.)
- **das Tempo** — pace
  *Mach dir keine Sorgen, wir laufen im lockeren Tempo.* (Don't worry, we run at an easy pace.)
- **sich aufwärmen** — to warm up
  *Wärmen wir uns erst kurz auf?* (Shall we warm up briefly first?)
- **die Kondition** — fitness / stamina
  *Meine Kondition ist noch nicht so gut, aber ich übe.* (My fitness isn't great yet, but I'm working on it.)
- **neu hier sein** — to be new here
  *Ich bin neu hier, das ist mein erstes Mal.* (I'm new here, this is my first time.)
- **"Wie weit laufen wir?"** — "How far are we running?"
  Feel free to ask this before you start, so you know what you're in for.
- **"Läufst du oft?"** — "Do you run often?"
  Small talk while running — a natural question to expect or ask back.

## Conversation simulation *(Screen 2)*

**Läufer 1:** Hallo! Bist du neu hier beim **Lauftreff**? *(Hi! Are you new to the **running club**?)*
**Sie:** Ja, ich bin **neu hier**. Ich heiße Sam. *(Yes, I'm **new here**. I'm Sam.)*
**Läufer 1:** Schön! Ich bin Lena. Wir **wärmen uns** kurz **auf**, dann geht's los. *(Nice! I'm Lena. We **warm up** briefly, then we start.)*
**Sie:** Super. **Wie weit laufen wir** heute? *(Great. **How far are we running** today?)*
**Läufer 2:** Die **Strecke** ist heute fünf Kilometer, ganz lockeres **Tempo**. *(The **route** is five kilometers today, a nice easy **pace**.)*
**Sie:** Perfekt, das passt zu meiner **Kondition**. *(Perfect, that matches my **fitness level**.)*
**Läufer 1:** **Läufst du oft**? *(**Do you run often**?)*
**Sie:** Ja, zwei- oder dreimal pro Woche. Ich freue mich schon! *(Yes, two or three times a week. I'm looking forward to it!)*

- Wasser dabei, falls die Strecke länger ist

## Recall check *(optional)*

A quick check now that you've actually run — no need to redo the full prep.

1. **Multiple choice** — Jemand fragt: "Läufst du oft?" Was antworten Sie, wenn das Ihr erstes Mal ist? *(Someone asks "Do you run often?" What do you answer if this is your first time?)*
   a) Nein, ich bin neu hier. b) Die Strecke ist fünf Kilometer. c) Ich wärme mich auf.
2. **Fill in the blank** — Nach dem Winter ist meine ___ nicht mehr so gut. *(After winter my ___ isn't so good anymore.)* (die Kondition)
3. **From real life** — What's one word or phrase you actually said or heard today? Write it in German.

## Level up

At B1, this scenario adds past-tense narration for after the run ("Wir sind fünf Kilometer gelaufen und haben uns danach unterhalten") instead of only present-tense small talk before/during.
