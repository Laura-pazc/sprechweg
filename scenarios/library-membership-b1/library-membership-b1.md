# Library Membership & Book Discussion

**Target language:** German (learner's source language: English) · **CEFR level:** B1 · **Register:** friendly/practical

## Key vocabulary

| German                                       | English                              |
| -------------------------------------------- | ------------------------------------ |
| die Bibliothek / Bücherei                    | library                              |
| der Ausweis                                  | library card / ID                    |
| das Buch / der Roman                         | book / novel                         |
| ausleihen / zurückgeben                      | to borrow / to return                |
| der Autor / die Autorin                      | author                               |
| die Lesegruppe                               | reading group                        |
| "Können Sie mir ein Buch über... empfehlen?" | "Can you recommend a book about...?" |
| "Wie lange kann ich das Buch behalten?"      | "How long can I keep the book?"      |

## Conversation simulation

**Bibliothekaerin:** Guten Tag! Ist das Ihr erstes Mal hier in unserer **Bibliothek**? _(Hello! Is this your first time at our library?)_

**Sie:** Ja, ich bin neu in Hamburg. Ich möchte einen **Ausweis** beantragen. _(Yes, I'm new to Hamburg. I'd like to apply for a library card.)_

**Bibliothekaerin:** Sehr gerne! Ich brauche Ihren Namen, Ihre Adresse und einen gültigen **Ausweis**. Die Mitgliedschaft ist kostenlos. _(Of course! I need your name, address, and a valid ID. Membership is free.)_

**Sie:** Wunderbar! **Können Sie mir ein Buch über Hamburg empfehlen**? Ich möchte die Stadt besser verstehen. _(Wonderful! Can you recommend a book about Hamburg? I'd like to understand the city better.)_

**Bibliothekaerin:** Ja! Ich habe einen guten **Roman** von Bodo Kirchhoff — er schreibt über Hamburg. Der **Autor** ist sehr beliebt hier. _(Yes! I have a good novel by Bodo Kirchhoff — he writes about Hamburg. The author is very popular here.)_

**Sie:** Das klingt interessant! **Wie lange kann ich das Buch behalten**? _(That sounds interesting! How long can I keep the book?)_

**Bibliothekaerin:** Sie können das Buch vier Wochen **ausleihen**. Danach müssen Sie es **zurückgeben** oder können es verlängern. _(You can borrow the book for four weeks. After that, you must return it or can extend it.)_

**Sie:** Perfekt. Gibt es auch eine **Lesegruppe** in der Bibliothek? _(Perfect. Is there also a reading group at the library?)_

**Bibliothekaerin:** Ja! Wir haben jeden Monat eine **Lesegruppe** am Dienstag. Das nächste Treffen ist in zwei Wochen. Möchten Sie teilnehmen? _(Yes! We have a reading group every month on Tuesday. The next meeting is in two weeks. Would you like to participate?)_

## Practice

1. **Multiple choice** — Wie lange kann man ein Buch aus der Bibliothek **ausleihen**? _(How long can you borrow a book from the library?)_
   a) Zwei Wochen b) Vier Wochen c) Sechs Wochen

2. **Fill in the blank** — Der **Ausweis** für die Bibliothek kostet nichts — die Mitgliedschaft ist \_\_\_. (kostenlos)

3. **Match the word to its meaning** — Match `die Lesegruppe`, `ausleihen`, `der Roman` to their English meanings above.

4. **Write a sentence** — using "der Autor," write one sentence about a German author you would like to read.

5. **Vocab review** — say all 8 key words/phrases aloud from memory before your library visit, in German.

## Level up

At B2, this scenario includes: detailed literary discussions using subjunctive mood ("Der Roman hätte besser sein können, wenn..."), articulate opinions about character development and plot ("Der Protagonist ist zu eindimensional geworden..."), participation in book club discussions with complex sentence structures and passive voice ("Das Buch ist von der Kritik hoch bewertet worden..."), and negotiating intellectual property or literature recommendation questions.
