# Yoga Class — First-Time Visit

**Target language:** German (learner's source language: English) · **CEFR level:** A1/A2 · **Register:** friendly
**Real-life mission:** Show up to a beginner yoga class and get through your first session.

## Key vocabulary _(Screen 1)_

Each word lives in a sentence, not just a translation:

- **der Yogakurs** — yoga class
  _Der Yogakurs beginnt um neun Uhr._ (The yoga class starts at nine.)
- **die Matte** — mat
  _Brauche ich eine eigene Matte, oder gibt es welche hier?_ (Do I need my own mat, or are there some here?)
- **sich dehnen** — to stretch
  _Am Ende dehnen wir uns noch kurz._ (At the end we stretch briefly.)
- **atmen** — to breathe
  _Atmen Sie tief ein und wieder aus._ (Breathe in deeply and out again.)
- **die Übung** — exercise / pose
  _Diese Übung ist gut für den Rücken._ (This exercise is good for your back.)
- **die Anfängerstunde** — beginner class
  _Ist das eine Anfängerstunde, oder für Fortgeschrittene?_ (Is this a beginner class, or for advanced students?)
- **bequeme Kleidung** — comfortable clothing
  _Tragen Sie bequeme Kleidung, in der Sie sich bewegen können._ (Wear comfortable clothing you can move in.)
- **"Ist hier noch frei?"** — "Is this spot still free?"
  Just ask this if you're looking for a place to put your mat.

## Conversation simulation _(Screen 2)_

**Teilnehmerin:** Hallo! Bist du neu hier im **Yogakurs**? _(Hi! Are you new to the **yoga class**?)_
**Sie:** Ja, das ist meine erste **Anfängerstunde**. _(Yes, this is my first **beginner class**.)_
**Teilnehmerin:** Schön! **Ist hier noch frei**? _(Nice! **Is this spot still free**?)_
**Sie:** Ja, klar! Brauche ich eine eigene **Matte**? _(Yes, of course! Do I need my own **mat**?)_
**Teilnehmerin:** Nein, wir haben Matten hier. Nur **bequeme Kleidung** ist wichtig. _(No, we have mats here. Only **comfortable clothing** matters.)_
**Lehrer:** Okay, alle bereit? Wir beginnen mit einer **Übung** zum **Atmen**. _(Okay, everyone ready? We start with a breathing **exercise**.)_
**Sie:** Ich versuche es! _(I'll try it!)_
**Lehrer:** Gut, jetzt **dehnen** wir uns langsam. _(Good, now we **stretch** slowly.)_

## Time to explore

You're ready. Book the class, or just show up if it's drop-in — then go.

Before you leave:

- Bequeme Kleidung an
- Du weißt, wo der Kurs stattfindet
- Eigene Matte, falls du eine möchtest

**[Ich gehe los]** _(I'm heading out)_ → **[Ich bin zurück]** _(I'm back)_

## Recall check _(optional)_

A quick check now that you've actually been — no need to redo the full prep.

1. **Multiple choice** — Sie haben Ihre Matte vergessen. Was fragen Sie? _(You forgot your mat. What do you ask?)_
   a) Habt ihr hier Matten? b) Ist hier noch frei? c) Wie oft kommt ihr her?
2. **Fill in the blank** — Man muss nichts Besonderes tragen, nur **_. \*(You don't need anything special, just _**.)\* (bequeme Kleidung)
3. **From real life** — What's one word or phrase you actually said or heard today? Write it in German.

## Level up

At B1, this scenario adds following longer spoken instructions during class (imperative chains like "Heben Sie die Arme, atmen Sie tief ein und halten Sie die Position") and small talk after class about how the practice felt, instead of only short present-tense exchanges before the session starts.
