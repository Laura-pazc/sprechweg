# Work Team Meeting — Understanding Discussion

**Target language:** German (learner's source language: English) · **CEFR level:** B1 · **Register:** formal
**Real-life mission:** Sit through a work meeting in German and actually follow — and contribute to — the discussion.

## Key vocabulary *(Screen 1)*

Each word lives in a sentence, not just a translation:

- **das Projekt** — project
  *Das Projekt ist zu siebzig Prozent fertig.* (The project is seventy percent done.)
- **der Fortschritt** — progress
  *Können Sie uns kurz den Fortschritt erklären?* (Can you briefly explain the progress to us?)
- **das Hindernis** — obstacle
  *Wir haben ein Hindernis: der Server ist zu langsam.* (We have an obstacle: the server is too slow.)
- **die Deadline** — deadline
  *Bis zur Deadline haben wir noch zwei Wochen.* (We still have two weeks until the deadline.)
- **besprechen** — to discuss
  *Heute besprechen wir den Stand des Projekts.* (Today we're discussing the status of the project.)
- **die Entscheidung** — decision
  *Das war eine gute Entscheidung.* (That was a good decision.)
- **"Können Sie das noch einmal erklären?"** — "Can you explain that again?"
  A polite, completely normal thing to ask in any meeting.
- **"Ich bin mir nicht sicher, ob ich das verstanden habe."** — "I'm not sure if I understood that."
  Softer than admitting you're lost outright.

## Conversation simulation *(Screen 2)*

**Teamleiterin:** Guten Morgen, alle zusammen. Heute **besprechen** wir den Stand des **Projekts**. Thomas, **der Fortschritt**, bitte? *(Good morning, everyone. Today we're **discussing** the status of the **project**. Thomas, **the progress**, please?)*
**Thomas:** Die Website ist siebzig Prozent fertig. Aber wir haben ein **Hindernis** — der Server antwortet zu langsam. *(The website is seventy percent done. But we have an **obstacle** — the server is responding too slowly.)*
**Sie:** Entschuldigung, **können Sie das noch einmal erklären**? *(Excuse me, **can you explain that again**?)*
**Thomas:** Der Server braucht zu lange, um die Daten zu laden. *(The server takes too long to load the data.)*
**Teamleiterin:** Das ist ernst — wir haben nur noch zwei Wochen bis zur **Deadline**. *(That's serious — we only have two more weeks until the **deadline**.)*
**Sie:** **Ich bin mir nicht sicher, ob ich das verstanden habe** — müssen wir den ganzen Code neu schreiben? *(**I'm not sure if I understood that** — do we need to rewrite the whole code?)*
**Kollegin:** Nur einen Teil, ich kann Ihnen dabei helfen. *(Just a part, I can help you with that.)*
**Teamleiterin:** Gut, das ist eine gute **Entscheidung**. Sam, arbeiten Sie mit ihr zusammen. *(Good, that's a good **decision**. Sam, work together with her.)*

## Recall check *(optional)*

A quick check now that you've actually sat through the meeting — no need to redo the full prep.

1. **Multiple choice** — Sie verstehen einen Punkt im Meeting nicht. Was sagen Sie? *(You don't understand a point in the meeting. What do you say?)*
   a) Können Sie das noch einmal erklären? b) Das ist eine gute Entscheidung. c) Wir haben noch zwei Wochen.
2. **Fill in the blank** — Wir haben ein ___ — der Server ist zu langsam. *(We have an ___ — the server is too slow.)* (Hindernis)
3. **From real life** — What's one word or phrase you actually said or heard today? Write it in German.

## Level up

At B2, this scenario adds participating actively in debates with counter-arguments ("Ich würde eher die API überarbeiten, weil...") instead of mainly asking clarifying questions.
