# Work Team Meeting — Understanding Discussion

**Target language:** German (learner's source language: English) · **CEFR level:** B1 · **Register:** formal
**Real-life mission:** Sit through a work meeting in German and actually follow — and contribute to — the discussion.

## Key vocabulary _(Screen 1)_

Each word lives in a sentence, not just a translation:

- **das Projekt** — project
  _Das Projekt ist zu siebzig Prozent fertig._ (The project is seventy percent done.)
- **der Fortschritt** — progress
  _Können Sie uns kurz den Fortschritt erklären?_ (Can you briefly explain the progress to us?)
- **das Hindernis** — obstacle
  _Wir haben ein Hindernis: der Server ist zu langsam._ (We have an obstacle: the server is too slow.)
- **die Deadline** — deadline
  _Bis zur Deadline haben wir noch zwei Wochen._ (We still have two weeks until the deadline.)
- **besprechen** — to discuss
  _Heute besprechen wir den Stand des Projekts._ (Today we're discussing the status of the project.)
- **die Entscheidung** — decision
  _Das war eine gute Entscheidung._ (That was a good decision.)
- **"Können Sie das noch einmal erklären?"** — "Can you explain that again?"
  A polite, completely normal thing to ask in any meeting.
- **"Ich bin mir nicht sicher, ob ich das verstanden habe."** — "I'm not sure if I understood that."
  Softer than admitting you're lost outright.

## Conversation simulation _(Screen 2)_

**Teamleiterin:** Guten Morgen, alle zusammen. Heute **besprechen** wir den Stand des **Projekts**. Thomas, **der Fortschritt**, bitte? _(Good morning, everyone. Today we're **discussing** the status of the **project**. Thomas, **the progress**, please?)_
**Thomas:** Die Website ist siebzig Prozent fertig. Aber wir haben ein **Hindernis** — der Server antwortet zu langsam. _(The website is seventy percent done. But we have an **obstacle** — the server is responding too slowly.)_
**Sie:** Entschuldigung, **können Sie das noch einmal erklären**? _(Excuse me, **can you explain that again**?)_
**Thomas:** Der Server braucht zu lange, um die Daten zu laden. _(The server takes too long to load the data.)_
**Teamleiterin:** Das ist ernst — wir haben nur noch zwei Wochen bis zur **Deadline**. _(That's serious — we only have two more weeks until the **deadline**.)_
**Sie:** **Ich bin mir nicht sicher, ob ich das verstanden habe** — müssen wir den ganzen Code neu schreiben? _(**I'm not sure if I understood that** — do we need to rewrite the whole code?)_
**Kollegin:** Nur einen Teil, ich kann Ihnen dabei helfen. _(Just a part, I can help you with that.)_
**Teamleiterin:** Gut, das ist eine gute **Entscheidung**. Sam, arbeiten Sie mit ihr zusammen. _(Good, that's a good **decision**. Sam, work together with her.)_

## Recall check _(optional)_

A quick check now that you've actually sat through the meeting — no need to redo the full prep.

1. **Multiple choice** — Sie verstehen einen Punkt im Meeting nicht. Was sagen Sie? _(You don't understand a point in the meeting. What do you say?)_
   a) Können Sie das noch einmal erklären? b) Das ist eine gute Entscheidung. c) Wir haben noch zwei Wochen.
2. **Fill in the blank** — Wir haben ein **_ — der Server ist zu langsam. \*(We have an _** — the server is too slow.)\* (Hindernis)
3. **From real life** — What's one word or phrase you actually said or heard today? Write it in German.

## Level up

At B2, this scenario adds participating actively in debates with counter-arguments ("Ich würde eher die API überarbeiten, weil...") instead of mainly asking clarifying questions.
